# mat — MultiAgent Tracker

[multi-agent-starter](https://github.com/netwaif/multi-agent-starter) 시스템의
작업 진행 상황을 터미널에서 모니터링하는 TUI 도구.

starter 시스템 없이 단독으로는 의미가 없다.

## 누가 이 도구를 쓰나

netwaif 채널의 MultiAgent 매뉴얼을 보고 starter를 설치한 학습자.

## 무엇을 보여주나 (MVP)

한 작업의 워커 현황을 한 화면에서 간결하게 본다.

- 현재 작업의 status / goal
- 워커 목록과 각 워커의 상태 (대기 / 실행 중 / 완료)
- 각 워커가 무엇을 하고 있는지 한 줄 요약

수동 새로고침 (`r` 키). 실시간 파일 watch는 안정성을 위해 MVP에서는 제외.
